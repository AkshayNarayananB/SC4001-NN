# ViewLayer+DAE: ViewLayer with a denoised view (and a test of VCD's contrast on top)

## Why

Phase 2 so far (TEST images, `fix_eval` scoring):

- **Everything that subtracts fails to improve discrimination.** VCD, the phase / mean nulls and the
  zero / shuffle hooks all tie or lose to the baseline on AUROC.
- **Everything that adds information helps.**
  - ViewLayer (blurred / flipped views read at layer 20): AUROC above baseline in 26/27 cells; blur s4 0.750 → 0.782, noise s4 0.737 → 0.817.
  - Fix B (DAE restoration, B0): noise s4 0.736 → 0.833. It leaves blurred and clean images unchanged.
- **VCD's contrast looked useful in one place.** Its unmasked score is below the baseline on clean
  images (−0.015 AUROC) but above it at the worst levels (+0.005 blur s4, +0.010 noise s4).

This experiment started as "ViewVCD": VCD's formula with a stronger real branch. DEV selection
switched the contrast off (α = 0), so the method that survives is ViewLayer plus the DAE view, and
the contrast variants are reported as an ablation.

## Method

```
score = (1 + α) · mean over views V of m_L(v)  −  α · m_L(v_cd)        answer "yes" if score > t
```

- `m_L(v)`: the Yes − No logit of view `v` read out at layer `L` through the final norm and the LM head.
- **Views V:** the degraded image, Gaussian-blurred copies (σ = 1, 2, 3 px), a horizontal flip, and the **DAE-restored copy** (`dae_v1`).
  - The DAE runs on every image, clean and blurred included, so the method never needs to know the degradation.
- **Contrast `v_cd`:** VCD's own diffusion-noised image, T = 999, with the same noise as the Stage 2 VCD runs.
- **No plausibility mask.** The answer is a Yes/No margin, and the mask is what forces 60–70% of VCD's POPE answers.

**Leakage-free selection.** V, L, α and t are chosen on the **100 DEV images only**, one global choice across all 27 cells.
- V, L and α maximise mean DEV AUROC. α comes from {0, 0.25, 0.5, 1, 2}.
- **α = 0 is in the grid**, so ViewLayer is a special case and the contrast is only used if it helps on DEV.
- t maximises mean DEV F1. The baseline gets its own DEV-tuned threshold in the F1 comparison.
- All reported numbers are on the **400 TEST images**.

**Variants reported** (each selected on DEV within its own search space):

| Variant | Search space | Question it answers |
|---|---|---|
| `vl_dae` (ViewLayer+DAE) | any V, L, α | the method |
| `no_contrast` | α = 0 | does the contrast term earn its place? |
| `viewlayer` | α = 0, no DAE view | reproduces `ViewLayer/README.md` |
| `forced_contrast` | α > 0 | what the contrast does when it must be used |
| `vcd_layer` | V = {orig}, α > 0 | plain VCD without the mask, read at layer L |

**Cost of the selected method.** 6 images per question (5 ViewLayer views + the DAE view), against 2 for VCD, plus one DAE pass per image (7.2M params). The contrast variants need a 7th image.

## Run

`run_viewlayer_dae.py` only computes the two new views (`dae`, `cd`). The other five come from the existing ViewLayer records, so the full ViewLayer run must be on disk.

```bash
# ASPIRE, from ~/SC4001-NN
qsub -J 4-8:4 -v LIMIT=30 ViewLayerDAE/run_viewlayer_dae.pbs   # smoke: blur s4 + noise s4
qsub ViewLayerDAE/run_viewlayer_dae.pbs                        # full: 9 conditions
python -m ViewLayerDAE.analyze                                 # -> results/viewlayer_dae_*.csv and the Results section below

python -m pytest ViewLayerDAE/tests -q                         # local CPU tests
```

Raw records: `$VCD_OUTPUT_ROOT/viewlayer_dae_<kind>_s<level>/<split>.jsonl` (32 layer margins × 2 views per question).

## Caveats

- The design was informed by TEST results of the earlier fixes (ViewLayer, Fix B, the unmasked-VCD AUROC). The *choices* (views, layer, α, threshold) are made on DEV only. Same caveat as ViewLayer.
- The search space is larger than ViewLayer's (19 view sets × 21 layers × 5 α on 100 DEV images), so some DEV overfitting is possible. The `viewlayer` variant and the paired CIs against it show how much of the gain is real.
- The DAE only helps noise. On blur and clean images the method equals ViewLayer on AUROC; its F1 there differs only through the shared DEV threshold.
- **Not yet compared with the DAE alone.** Fix B's B0 (noise s4 AUROC 0.833) was scored on all 500 images at the final layer, so it is not directly comparable with the 0.833 here. Rescore Fix B through `fix_eval/common.py` before claiming the combination beats the DAE alone.
