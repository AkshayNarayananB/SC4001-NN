# Fix 2: phase-scrambled null contrast

## Why (from Stage 2, `docs/findings.md`)

On degraded POPE images VCD's F1 gain grows with severity, but the gain is only a Yes/No threshold
shift. VCD **lowers AUROC in every cell**, and a baseline whose threshold is moved to VCD's yes-ratio
matches or beats it. One cause: VCD's contrast image is not blind. At T=999 its Yes/No margin
still separates present from absent objects with AUROC 0.69 on clean images (faint objects are
visible: `results/fix2_nulls_examples.png`). Subtracting it therefore subtracts real evidence.

## What

Replace the diffusion-noise contrast image with a **null**: an image with the degraded input's
low-level statistics but none of its objects.

**Phase null (the fix).**
1. Take the 2D FFT of the normalized input tensor.
2. Keep the amplitude spectrum and add a random phase field. The phase comes from the FFT of white noise and is shared by the RGB channels.
3. Inverse FFT, then clip to the valid pixel range.

The phase carries object structure (Oppenheim & Lim, 1981). The amplitude carries blur level, noise
level, contrast and colour, so a blurred input gives a blurry texture and a noisy input a grainy
one. The contrast step is unchanged VCD: `(1+α)·l(y|v) − α·l(y|v_null)`, with the plausibility
mask at β=0.1. It costs one extra forward pass, like VCD. There's no training and no degradation
estimate.

**Mean null (control).** Every pixel is set to the input's channel mean. It is content-free and
colour-matched, but has no spectrum. Comparing it with the phase null shows whether matching the
input's statistics matters, or whether removing content is enough.

## Success criteria (set by Stage 2)

The fix has to clear both bars that VCD failed:
1. **AUROC above baseline**, with a paired-bootstrap CI above 0. VCD's is below 0 in every cell.
2. **F1 above the matched-threshold baseline**. Otherwise the gain is just a bias shift.

Also reported:
- **AUROC of the null branch alone.** It should be ≈0.5, which checks that the null really is content-free.
- **F1 and yes-ratio** against baseline and VCD.
- **JS(real ‖ null).**

## Held-out protocol (handout: test data separate from development)

POPE's 500 images are split by image, with a fixed seed, into 100 **DEV** and 400 **TEST** images.
α is chosen per null on DEV only, from {0.25, 0.5, 1, 2, 3}, by maximising mean AUROC over all 27
condition × split cells. Every TEST number uses that one α. VCD keeps the paper's α=1 (Stage 0).

## How it runs

Stage 2 already logged the real-branch and VCD first-token logits for every question. So
`run_nulls.py` only needs one batched forward per question: real + phase null + mean null. It
logs:
- Yes/No logits per branch;
- JS divergence;
- the exact full-vocabulary greedy first token under the VCD rule, for every α.

POPE answers are one word, so the first token decides the answer. `analyze.py` joins these with
the Stage 2 records.

```bash
# on ASPIRE, from ~/SC4001-NN
qsub -J 4-8:4 -v LIMIT=30 model_fix_2/run_nulls.pbs   # smoke: blur s4 + noise s4, 30 q/split
qsub model_fix_2/run_nulls.pbs                        # full: 9 conditions x 3 splits x 3000 q
python -m model_fix_2.analyze                         # -> results/fix2_alpha_dev.csv, fix2_comparison.csv
python -m model_fix_2.show_nulls                      # -> results/fix2_nulls_examples.png

# locally (CPU, no weights)
python -m pytest model_fix_2/tests -q
```

Raw records: `$VCD_OUTPUT_ROOT/fix2_nulls_<kind>_s<level>/<split>.jsonl`. Smoke runs go to
`..._limit<N>/`, so they never mix with the full run.

## Files

- `nulls.py`: phase and mean nulls, seeded by image name, so the same photo gets the same random phase at every level and in every split.
- `run_nulls.py`: null-branch logits and exact first-token decisions.
- `analyze.py`: DEV α sweep, TEST comparison, bootstrap CIs. Reuses `auroc`/`f1_from` from `scripts/analyze.py`.
- `show_nulls.py`: example figure.
- `tests/`: properties of the nulls, plus the margin recomputation against the full VCD rule.

## Known limitations

- The amplitude spectrum still carries some scene "gist" (Oliva & Torralba). A savanna texture may raise the prior for "giraffe". The null-branch AUROC measures how much.
- FFT periodicity puts faint grid lines on very smooth images (e.g. snow). Mirror-padding before the FFT would remove them; not done.
- Scrambling acts on the normalized 336 px tensor. Clipping to the valid range slightly changes the amplitude on high-contrast images.
- Like VCD, the null only removes priors. It can't recover evidence the degradation destroyed, so at s4 every method stays well below clean.
