# RITUAL: random image transformations as a complementary view

**Paper:** Woo et al., *RITUAL: Random Image Transformations as a Universal Anti-hallucination Lever in
LVLMs*, arXiv 2405.17821 (2024). No official code repository is linked; this is a reimplementation
from the paper (Eq. 4, Sec. 4.1, App. E.1).

## Idea

VCD *subtracts* a corrupted view of the image. RITUAL *adds* a transformed view instead:

`p_RITUAL(y) = p(y | v, x) + α · p(y | T(v), x)`

- `T` is one random transformation per image: horizontal flip, vertical flip, rotation U(−180°, 180°),
  colour jitter (1, 1, 1, 0.5), Gaussian blur (kernel 13, σ U(1.5, 2)) or a random 336 px crop.
- α = 3 (paper default).
- VCD's plausibility constraint on the original distribution, β = 0.1.

The second view gives the model another look at the same evidence. Where the original view's answer
is fragile, the transformed view can correct it.

**Why it fits our problem.** Stage 2 showed that VCD's gain on degraded POPE images is only a yes/no
threshold shift: it lowers AUROC everywhere. A method that pools evidence across views is the
natural candidate for actually *raising* AUROC.

**How it differs from the other fixes.**
- **#1 (zeroed visual KV-cache) and #2 (shuffled positional encodings):** both blind a second pass and subtract it. RITUAL blinds nothing and subtracts nothing.
- **Fix B (DAE):** Fix B restores the pixels with a trained network. RITUAL leaves the image untouched and adds an extra view.
- **model_fix_2:** model_fix_2 changes VCD's comparison image. RITUAL changes the real side.

## Our protocol

- LLaVA-1.5-7B, POPE MSCOCO (3 splits × 3000 questions), clean + blur s1–4 + noise s1–4.
- Same prompt and images as Stages 0–2.
- **Greedy** decoding, to match the Stage 2 baseline and VCD runs (the paper samples).
- POPE answers are one word, so the exact greedy first token decides the answer.
- One batched forward per question runs the original + all six views. The README reports:
  - **RITUAL as published:** the image's one random view, α = 3. No tuning.
  - **RITUAL with α chosen on DEV images:** 100 DEV images, results on the other 400 TEST images.
  - **All six views averaged** (the paper's multi-view ablation).
  - **A per-transform ablation:** which views help degraded images.
- Scored like every Phase 2 fix (`fix_eval/common.py`): AUROC vs baseline and VCD, F1 vs the
  matched-threshold baseline, 95% paired-bootstrap CIs.

## Run

```bash
# ASPIRE, from ~/SC4001-NN
qsub -J 4-8:4 -v LIMIT=30 RITUAL/run_ritual.pbs    # smoke: blur s4 + noise s4, 30 q/split
qsub RITUAL/run_ritual.pbs                         # full: 9 conditions
python -m RITUAL.analyze                           # fills in the Results section below

python -m pytest RITUAL/tests -q                   # local CPU tests
```

Raw records: `$VCD_OUTPUT_ROOT/ritual_<kind>_s<level>/<split>.jsonl`.

## Deviations from the paper

- Greedy decoding instead of sampling, for comparability with Stage 2.
- Transforms are applied to the degraded image at native resolution. Their parameters are seeded
  per image, so the same photo gets the same view at every degradation level and in every split.
- RITUAL's own Gaussian-blur view is kept, to stay faithful, even though our inputs may already be
  blurred. The per-transform ablation shows its effect separately.
